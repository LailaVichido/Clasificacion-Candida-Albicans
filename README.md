# Clasificación Morfológica de Candida Albicans 🍄🔬

Este proyecto utiliza técnicas de **procesamiento de imágenes** para identificar la morfología de la *Candida Albicans*. Este hongo es un habitante común del cuerpo humano, pero su transición morfológica puede indicar un estado patológico.

## 🚀 Objetivo
Desarrollar una herramienta que permita clasificar automáticamente las fases del hongo para apoyar el diagnóstico clínico mediante visión artificial.

## 🛠️ Tecnologías utilizadas
* [cite_start]**Lenguaje:** Python / MATLAB.
* [cite_start]**Técnicas:** Segmentación morfológica y extracción de descriptores de forma.
